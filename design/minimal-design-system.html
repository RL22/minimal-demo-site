10 · Accessibility

WCAG 2.2 AA is the baseline

The system treats accessibility as component behavior: contrast, states, focus, semantics, input support, and responsive reflow are part of every definition.

Perceivable

  • Normal text contrast ≥ 4.5:1
  • UI and large text contrast ≥ 3:1
  • Meaning never relies on color alone
  • Charts provide text alternatives

Operable

  • All controls work with a keyboard
  • Visible 2px focus treatment
  • 44×44px preferred targets
  • Reduced-motion equivalent

Understandable

  • Visible labels and instructions
  • Textual, associated errors
  • Consistent component behavior
  • Predictable navigation placement

Robust

  • Semantic HTML before ARIA
  • Landmarks and heading order
  • Live regions for status changes
  • Test at 320px and 400% reflow
